# 서울 지하철을 만들자

구 안의 빈 땅에 역을 마음대로 놓고 노선을 잇는 지하철 경영 게임.
역 자리는 플레이어가 정하지만, 손님은 실제 서울 지하철 승객 통계로 움직입니다.

## 해 보기

```
python3 -m http.server 8000
```
http://localhost:8000/ 로 들어가면 됩니다. (`index.html` 을 파일로 바로 열어도 돌아갑니다.)

## 규칙 한눈에

- **빈 땅을 누르면** 걸어서 800m 안에 사람이 얼마나 있는지, 아직 역이 안 닿는 사람이 얼마인지 보입니다.
- **역을 누르면** 새 노선을 시작하거나, 끝 역이면 그대로 이어갈 수 있습니다. 잇는 중에 빈 땅을 누르면 역을 지어 바로 잇습니다.
- **손님**은 실제 역간 이동 자료로 계산합니다. 갈 곳이 노선으로 이어져야 타고, 오래 걸리면 덜 탑니다.
- **역을 너무 붙이면** 손님을 나눠 갖고, 서는 횟수만큼 노선이 느려집니다.
- **역이 안 닿는 동네**에는 주민 불만(😠)이 쌓여 평판과 수입이 떨어지고, 민원(기한 안에 역을 열면 지원금)이 옵니다.
- 평소엔 내가 지은 곳만 가까이 보이고, `전체 보기` 로 서울 전체 역을 볼 수 있습니다.

## 폴더

```
index.html      게임
game_data.js    고른 구의 자료 (tools/build_free.py 가 만든다)
data/           원자료 — 역_승객자료.json(역·승차·역간 이동), 서울_자치구_경계.json 등
tools/          자료를 만드는 파이썬
docs/           정리 문서 (옛게임_* 은 v69까지의 이전 게임 기록)
```

## 지역 바꾸기

```
python3 tools/build_free.py                       # 강남구 서초구 송파구 (기본)
python3 tools/build_free.py 관악구 동작구 영등포구
```
서로 붙어 있는 구를 고르는 것이 좋습니다.
