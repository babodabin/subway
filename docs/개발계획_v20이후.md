# 서울 지하철을 만들자 — v20 이후 개발계획

핵심 반복: **노선 설계 → 승객 발생 → 문제 발견 → 개선 → 수익과 도시 성장 → 재설계**

## 원칙

- 실제 서울·수도권 역 자리와 수요는 유지한다.
- 역 이름은 기본 이름을 쓰거나 플레이어가 바꿀 수 있다.
- 노선 연결, 순서, 환승 구조, 이름과 색은 플레이어가 정한다.
- 지도는 공식 노선도식 모양을 유지한다. 실제 거리와 화면 선 길이는 분리한다.
- 자동 기능은 편의를 주되, 서로 다른 전략적 선택을 없애지 않는다.

## 단계

1. **실제 거리 분리 (v20, 완료)**
   - 공식 노선도 좌표는 화면에만 사용한다.
   - 기존 역간 자료는 그대로 쓰고, 새 연결은 위·경도 직선거리로 계산한다.
   - 거리로 공사비와 운행시간을 계산한다.

2. **내 노선 편집 (v25, 완료)**
   - 노선 이름·색 변경 (v21 완료)
   - 양 끝 연장에 더해 기존 구간에 중간역 삽입 (v23 완료)
   - 끝역 단축 및 폐선 (v24 완료)
   - 수정 전에 공사비·거리·운행시간·이용객·표값 수입 변화 예상 표시 (v25 완료)
   - 양끝뿐 아니라 원하는 중간역 제거와 변화 미리보기 (v63 완료)

3. **환승과 병목 (v29, 완료)**
   - 환승역 대합실 용량, 환승 거리와 시간 (v29 완료)
   - 환승 혼잡 표시와 지도 경고 (v29 완료)
   - 환승통로·대합실 확장 공사와 전후 효과 미리보기 (v29 완료)

4. **운행계통 (진행 중 — 남은 것은 여기뿐)**
   - 상세 주행·정차·회차·왕복시간과 필요 편성 표시 (v30 완료)
   - 완행·급행 (v31 첫 구현 완료)
   - 구간 운행과 지선 셔틀 (자유 구간운행 v33 완료, **실제 분기 지선은 아직**)
   - 같은 선로를 공유하는 운행계통 (직결운행 v35 첫 구현 완료)

5. **역 성장 (v55, 완료)**
   - 접근성 개선에 따른 장기 수요 증가 (v36 완료)
   - 주거·업무·상업 성격 변화 (30일차부터 역세권 개발 v55 완료)
   - 역 등급과 상가 가치 변화 (상가 22종 v38, 역 승급 v39 완료)

6. **경영과 사건 (v59, 완료)**
   - 대출, 보조금, 공공성 목표 (v40 첫 구현)
   - 공사 지연, 민원, 재개발, 축제 (민원·재개발·공사 지연 v43 완료)
   - 무조건 정답이 아닌 위험·보상 선택지 (사건별 선택 v42 완료)
   - 30일 운영 결산과 운영 분석·자금 소진 예상 (v50·v51 완료)
   - 차량 정비와 역 시설 노후화·보수 (v53·v54 완료)
   - 승객 구성과 시민 지원 (v56 완료)
   - 30일·100일 경영 평가, 등급별 지원금, 100일 칭호 (v57·v58 완료)
   - 30일차부터 고르는 공공성·수익·예방정비 운영 정책 (v59 완료)

7. **정보 화면과 균형 (v69, 완료)**
   - 노선 수정 전후 예상 승객·시간·수익 비교 (혼잡·운영비·회수기간 v46 완료)
   - 승객이 선택한 경로와 못 탄 이유 표시 (못 탄 이유 v44, 경로 보기 v45 완료)
   - 여러 시작 자금과 난이도, 장기 목표 (난이도 v47, 장기 목표 v48, 난이도 경제 v52, 최종 조정 v66 완료)
   - 초보 임무와 도전 계약 (v49·v64 완료)
   - 승객 흐름 시각화와 붐비는 역 순위 (v62 완료)
   - 초반 경제 균형 조정 (v61 완료)
   - 게임 안내서, 효과음, 일시정지, 저장 보호 (v67·v65·v68·v69 완료)

각 단계는 구현 후 저장·모바일·장기 시뮬레이션 회귀 테스트를 통과한 뒤 다음 단계로 간다.

## 지금 남은 것

- **분기 지선** — 4단계에서 유일하게 남은 항목. 본선에서 갈라지는 실제 지선과 그 운행계통.
